# CI staging for MAGE-1730

This directory holds the intended `.github/` end state for moving klaviyo-expo-plugin onto the shared mobile SDK CI in klaviyo-react-native-sdk (`.github/shared/` plus `release-preflight.yml` and `rel-branch-core.yml`, pinned to `@ecm/mage-1726/shared-ci` until that branch merges). To apply it, copy `ci-staging/github/*` over `.github/` (full files, same relative paths), delete every path listed in `ci-staging/DELETE`, then remove `ci-staging/`. After the change, `publish-release.yml` calls `release-preflight.yml` and passes the Expo version-stamp and native-pin checks through `sdk-checks`. `rel-branch.yml` calls `rel-branch-core.yml` and keeps its own trigger and `pin` job. `pr-target-check.yml`, `stale.yml` and the new `promotion-check.yml` are short stubs over the shared actions. `publish-sdk.yml` uses `linear-release-sync`, `publish-example.yml` uses `remove-deploy-label`, and every Slack post uses the remote `notify-slack`, so the local `.github/actions/notify-slack` copy and its `_slack` sparse checkouts go away. The npm publish steps, the example-app deploy bodies, `set-source-label`, `setup-eas`, `dependabot.yml` and `scripts/ci/*` don't change.
